# 五行城市命书 · Your Elemental City

> 用 12 道不太正经的问题，测出你的五行人格，找到与你生活节奏更合拍的那座城。
> 东方命理 × 复古旅行手账 × 单文件网页应用

**在线体验**：（部署后在此补充链接）｜**本地体验**：直接双击 `index.html` 即可，无需任何环境。

---

## 这是什么

一个纯前端的趣味测试网站。整个项目只有一个 `index.html` 文件——不依赖任何外部图片、字体、CSS/JS 库或网络请求，断网也能完整运行。

流程共五幕：

| 幕 | 内容 |
|---|---|
| ① 序章 | 五行百科：木火土金水五种"城市生存人格"卡片 + 手账风拼贴插画 |
| ② 问答 | 12 道怪味情景题（灵魂是一种什么家用电器？），支持回退修改答案 |
| ③ 生成仪式 | 五行轮转动画 + "正在推演五行之间的关系……"的仪式感加载 |
| ④ 命书结果 | 人格称号、五行能量分布、主次格相生相克解读、主荐城市档案 |
| ⑤ 城市探索 | 22 座城市数据库，可自由切换查看，原测试结果始终保留 |

## 特色

- **五行相生相克引擎**：主格 × 次格的组合会产生"相生（互相滋养）/ 相克（互相制衡）"两种解读；城市与人格之间也遵循 木生火、火生土…… 与 木克土、土克水…… 的关系矩阵
- **可解释的推荐算法**：每座城市按「五行契合 40 + 生活节奏 20 + 场景偏好 24 + 发展方向 16」四个维度打分，结果页会展示每一项的具体得分
- **22 座城市 × 22 幅手绘风 SVG 插画**：东方明珠、天坛、平安金融中心、广州塔、雷峰塔、黄鹤楼、洪崖洞山城、天津之眼……全部为参数化生成的内嵌 SVG，矢量无限缩放
- **城市自由切换**：不锁定结果，可查看任意备选城市的完整档案，一键返回主荐城市
- **一键复制文案 + Canvas 分享卡片**：1080×1350 竖版分享图（微信朋友圈尺寸），本地 Canvas 绘制，点击即下载
- **响应式 + 无障碍**：320px 小屏到桌面全适配；尊重系统"减少动态效果"设置，自动跳过生成仪式动画

## 技术实现

| 约束 | 方案 |
|---|---|
| 单文件交付 | HTML + CSS + JS 全部内联于 `index.html`（约 100KB） |
| 零外部资源 | 字体走系统衬线字体栈；纸纹/插画全部为内嵌 SVG 与 data URI |
| 离线可用 | 无任何网络请求，`file://` 协议直接打开即可完整运行 |
| 逻辑可测试 | 计分/画像/排序为纯函数，通过 Node.js 导出做了 225 项断言的单元冒烟测试 + jsdom 全流程 E2E 测试 |
| 分享卡片 | SVG 经 `encodeURIComponent` 转 data URL 栅格化，不污染 Canvas，离线可生成 |

## 打分算法

```
城市总分 = 五行契合(0-40) + 生活节奏(0-20) + 场景偏好(0-24) + 发展方向(0-16)
契合度   = 52 + 总分 × 0.45，并限制在 [52, 97] 区间
```

五行契合档位：城市 = 主格(40) ＞ 城市 = 次格(26) ＞ 城市生你(20) ＞ 你生城市(16) ＞ 你克城市(13) ＞ 城市克你(10)。

## 如何运行

- **本地**：双击 `index.html`（或拖入任意浏览器）
- **部署**：任意静态托管均可——GitHub Pages / Vercel / Netlify，只需托管这一个文件
