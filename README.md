# 五行城市命书

> 用 12 道不太正经的问题，测出你的五行人格，找到与你生活节奏更合拍的那座城。
> 东方命理 × 复古旅行手账 × 单文件网页应用

**在线体验**：（部署后在此补充链接）｜**本地体验**：直接双击 `index.html` 即可，无需任何环境。

---

## 这是什么

一个纯前端的趣味测试网站。整个项目只有一个 `index.html` 文件——不依赖任何外部图片、字体、CSS/JS 库或网络请求，断网也能完整运行。

流程共五幕：

| 幕 | 内容 |
|---|---|
| ① 序章 | 五行百科：木火土金水五种「城市生存人格」卡片 + 手绘五行图腾 + 夜景群像主视觉 |
| ② 问答 | 12 道日常共鸣选择题（班味儿、松弛感、搭子……），支持回退修改答案 |
| ③ 生成仪式 | 五行轮转仪式动画 + Canvas 粒子金属水晶特效（约 290 粒子、五边形星阵） |
| ④ 命书结果 | 拆成 4 个独立翻页：① 主荐城市 + 生活发展建议 ② 另外两座适配城市 ③ 五行能量图谱 + 相生相克解读 ④ 命书小结 + 操作区。主荐城市插画出现时叠加与五行同色系的粒子动效 |
| ⑤ 城市探索 | 20 座城市数据库，可自由切换查看，原测试结果始终保留 |

## 特色

- **五行相生相克引擎**：主格 × 次格的组合会产生"相生（互相滋养）/ 相克（互相制衡）"两种解读；城市与人格之间也遵循 木生火、火生土…… 与 木克土、土克水…… 的关系矩阵
- **可解释的推荐算法**：每座城市按「五行契合 40 + 生活节奏 20 + 场景偏好 24 + 发展方向 16」四个维度打分，结果页会展示每一项的具体得分
- **20 座城市 × 20 幅 AI 夜景插画**：每座城市配一幅 1080×1440 的专属城市夜景（东方明珠、西湖、鼓浪屿、洪崖洞、钟楼……），未命中时自动回退到参数化内嵌 SVG 插画
- **五行粒子动效**：金＝金属碎片、木＝落叶飘升、水＝水滴涟漪、火＝火星升腾、土＝暖金沙尘，随主荐城市出现/离开自动启停
- **整页水墨背景**：全站铺一幅浅化处理的水彩波纹背景，随页面切换自动调节深浅与远近（序章最透、问答与结果蒙纱、仪式最静），突出内容主体
- **水晶音效**：5 段内嵌音效（水晶钟 / 精灵闪光 / 光之法术 / 魔杖星屑 / 轻触散开），经高通去闷 + 合成混响处理；播放时从五声音阶随机选调并左右偏移声场，空灵不重复；右上角可一键开关
- **城市自由切换**：不锁定结果，可查看任意备选城市的完整档案，一键返回主荐城市
- **一键复制文案 + Canvas 分享卡片**：1080×1350 竖版分享图（微信朋友圈尺寸），本地 Canvas 绘制，点击即下载
- **响应式 + 无障碍**：320px 小屏到桌面全适配；键盘 1–4 选项、←→ 翻题、Esc 关灯箱；尊重系统"减少动态效果"设置，自动降级跳过仪式动画

## 技术实现

| 约束 | 方案 |
|---|---|
| 单文件交付 | HTML + CSS + JS + 全部图片内联于 `index.html`（约 6.5MB） |
| 图片内嵌 | 5 张图腾（透明底 PNG 360px）+ 序章主视觉（2002×1648 JPEG）+ 20 张城市插画（1080×1440 JPEG，总计约 3.9MB），全部为 data URI |
| 零外部资源 | 字体走系统衬线字体栈；纸纹/插画为内嵌 SVG 与 data URI |
| 离线可用 | 无任何网络请求，`file://` 协议直接打开即可完整运行 |
| 逻辑可测试 | 计分/画像/排序为纯函数，另用 jsdom 跑两套无头回归：全按钮 QA + 全流程 E2E |
| 分享卡片 | 优先用城市插画等比裁剪填充；Canvas 不可用时给出降级提示而非报错 |
| 构建流程 | `_dev/` 下维护轻量源文件 + 注入脚本，把美术资源注入占位标记后产出单文件成品 |

## 打分算法

```
城市总分 = 五行契合(0-40) + 生活节奏(0-20) + 场景偏好(0-24) + 发展方向(0-16)
契合度   = 52 + 总分 × 0.45，并限制在 [52, 97] 区间
```

五行契合档位：城市 = 主格(40) ＞ 城市 = 次格(26) ＞ 城市生你(20) ＞ 你生城市(16) ＞ 你克城市(13) ＞ 城市克你(10)。
